# Plantillas de registros

Copiar cada plantilla necesaria al repositorio institucional restringido fuera de `htdocs` y Git. Estas son plantillas vacías; no representan autorizaciones ni actividades realizadas. Campos comunes: ID único, versión, fecha/hora y zona, autor, clasificación, ubicación de evidencia, acceso autorizado, retención aprobada y próxima revisión. Si un campo aún no tiene evidencia, marcar «pendiente», no «cumple».
